# Support

Ebbli Community OS is pre-release community software maintained on a best-effort basis.

- Use GitHub Discussions, when enabled, for setup questions and design discussion.
- Use the issue templates for reproducible bugs and scoped feature proposals.
- Use the private route in [SECURITY.md](SECURITY.md) for vulnerabilities.

There is no guaranteed response time, production SLA, hosted service, or emergency support.
Do not deploy the project for sensitive production workflows without an independent security,
privacy, accessibility, and operational review.
