# Maintainers

## Primary maintainer

Ben Kiruthi ([`@benkiruthi`](https://github.com/benkiruthi)) is currently the sole primary
maintainer.

Responsibilities include architecture stewardship, issue triage, pull-request review,
release management, security coordination, migration/RLS review, documentation,
responsible-AI review, and contributor support. This is a best-effort role with no response
time guarantee.

## Becoming a maintainer

Trusted contributors may progress from contributor to reviewer and then module maintainer
through sustained, constructive work; sound security/privacy judgment; reliable review;
and alignment with the project mission and Code of Conduct. Access is granted narrowly and
reviewed over time.

To reduce bus-factor risk, decisions should be recorded in issues or pull requests,
releases should use documented checks, and credentials must not depend on undocumented
personal systems. Future maintainers will be listed here with explicit scope.
