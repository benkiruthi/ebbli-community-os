# Adoption

**Public adoption evidence is not yet available.**

No outside users, deployments, pilots, package downloads, testimonials, or partner
organizations are claimed. Intended use cases include nonprofits, schools, churches,
alumni networks, civic groups, and community ventures; intended use is not actual usage.

## Ethical evidence plan

1. Publish one clearly limited reference deployment using synthetic data.
2. Run one consented nonprofit or community pilot.
3. Ask a non-maintainer to complete and document a clean installation.
4. Run a contributor-onboarding test and collect feedback in a public issue.
5. Publish a throttled-network benchmark and performance budget.
6. Complete an accessibility review with tracked remediation.
7. Demonstrate one localization proof of concept.

Names, logos, quotes, and metrics require permission and verifiable sources. Failed pilots
and limitations should be reported, not hidden.
